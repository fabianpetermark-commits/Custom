# Hangszóródoboz — 3D terv

Paraméteres hangszóródoboz-terv OpenSCAD-ben. A repo gyökerében lévő
Splat Run projekttől független — külön mappában él, mert más témában, más
életciklussal fut.

## Állapot

A projekt jelenleg a nulláról indul, még nincsenek eldöntött
specifikációk (meghajtó mérete, doboz típusa, cél térfogat, külső
méretkorlát). A `box.scad` egy üres kiindulási sablon, amit az első
konkrét specifikáció megérkezésekor töltünk fel valós méretezéssel.

## Ide tartozik

- `box.scad` — a paraméteres terv forrása.
- Bármilyen exportált fájl (pl. `.stl`), ha a terv nyomtatásra kész.
