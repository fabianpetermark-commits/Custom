# Csopark

Python kódbázis, korábban Google Drive-on tárolva, ide áthozva ebbe a
mappába. A repo gyökerében lévő Splat Run projekttől független — külön
mappában él, mert más témában, más életciklussal fut.

## Állapot

Még nincs feltöltve a tényleges kód. A fájlok egy megosztott Google Drive
linkről kerülnek majd ide.

## Ide tartozik

- A Csopark Python kódja és a hozzá kapcsolódó fájlok.
